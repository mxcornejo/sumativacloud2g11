# Matriz de cobertura de la pauta

| Criterio | Evidencia preparada | Cierre requerido |
|---|---|---|
| 1. Implementación de funciones (10 puntos) | Cuatro CRUD REST/GraphQL y dos funciones Java EDA | Funciones publicadas y demostradas |
| 2. Configuración EDA (15) | Topic, suscripción, filtro y variables | Captura de configuración real |
| 3. Integración completa (15) | CRUD → Oracle/outbox → publicador → Topic → consumidor → auditoría | IDs correlacionados y prueba real |
| 4. Finalidad de componentes (10) | Informe y responsabilidades | Explicación de ambos integrantes |
| 5. Precisión del diagrama (10) | Diagrama EDA editable | Mostrarlo coherente con el despliegue |
| 6. Selección tecnológica (10) | Azure/Java, Oracle y continuidad EC2 | Justificación técnica en video |
| 7. Cobertura del diagrama (10) | REST, GraphQL, outbox, publicación y consumo | Recorrer todas sus flechas |
| 8. Video (10) | Guion de 7 minutos | Grabación real y enlace accesible |
| 9. Git colaborativo (10) | Repositorio anterior y cambios preparados | Publicación y aportes verificables de ambos |

No se asigna una nota estimada. El resultado lo determina el docente con la evidencia entregada.
